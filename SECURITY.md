# Security Policy

AI Employee OS can process customer, property, scheduling, and communication data. Treat logs, transcripts, exports, and provider credentials as sensitive.

Do not report suspected vulnerabilities in a public issue. Contact the maintainer privately at [jacobstephane@outlook.com](mailto:jacobstephane@outlook.com) with a concise description and safe reproduction steps. Do not include real credentials, customer data, or unredacted production transcripts.

This prototype has not received an independent security audit. Do not use it as the sole system of record for safety-critical or regulated workflows.

Contact: Stephane Jacob <jacobstephane@outlook.com>
